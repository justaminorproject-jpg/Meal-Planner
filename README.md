# Meal-Planner
AI-powered meal planner PWA — generates personalized 1–7 day meal plans with real recipes, grocery lists, YouTube how-to links, star ratings, and a built-in brand sponsorship engine with pay-per-pull billing. 

AI Meal Planner is a full-featured Progressive Web App (PWA) that uses Claude AI to generate personalized meal plans from real web recipes. Users choose their dietary preferences, cuisine types, and meal styles — the app builds a complete plan with ingredients, step-by-step instructions, calorie info, and YouTube how-to video links for every meal.

Built-in monetization includes a sponsor management system (pay-per-pull brand badge injection into ingredient lists), Google AdSense slots, Amazon Associates affiliate links, and Instacart affiliate integration. A password-protected admin panel handles sponsor setup, billing tracking, and ad configuration.

Installable on iOS, Android, Mac, and Windows with no app store required. Automatic fallback to Groq Llama 3.3 if Claude is unavailable.
